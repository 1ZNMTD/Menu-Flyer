# 使い方

## 毎日の流れ（おすすめ）

| タイミング | やること | 目安 |
|---|---|---|
| 朝 | まとめメール（7時）を見る → 画面の **未整理** を仕分け（採用 / 却下） | 3〜5分 |
| 随時 | 電話・口頭・思いつきは、その場で **クイック追加** か **📞 電話メモ** | 10秒 |
| AI と作業した後 | 会話の最後に「定型文」を送り、出力を **📋 AI・メモ取込** に貼る | 1分 |
| 夕方 | **今日** タブを見て、終わったものにチェック。残りは期限を見直す | 3分 |
| 週1回 | **待ち** と **すべて** を見て、止まっているものを確認。Gmail フィルタの条件を見直す | 10分 |

**「未整理」を毎日ゼロにする** ことが、取りこぼし防止のいちばんのコツです。

## 画面の見かた

| タブ | 表示されるもの |
|---|---|
| 未整理 | 自動取込された候補。**採用**（未着手へ）/ **編集して採用** / **待ちにする** / **却下** / 元メールを開く |
| 今日 | 期限切れ・今日が期限・進行中のタスク |
| 予定 | 期限が明日以降のタスク、期限なしのタスク |
| 待ち | 相手の返事待ちなど、自分の手を離れているもの |
| すべて | 未着手・進行中・待ちの全部 |
| 完了 | 完了・却下（直近100件）。却下を「未整理に戻す」ことも可 |

- チェックボックス = 完了。もう一度押すと未着手に戻る
- タスクをタップ = 編集（タイトル・期限・優先度・状態・依頼者・連絡先・タグ・メモ）
- 右上 **✉ 取込** = 15分を待たずに今すぐ Gmail を取り込む
- 検索窓 = タイトル・メモ・依頼者・タグ・出典で絞り込み（スペース区切りで AND）

## クイック追加の書き方

```
見積書を作成 @金曜 !高 #案件A >山田
```

| 記号 | 意味 | 例 |
|---|---|---|
| `@` | 期限 | `@2026-10-20` `@10/20` `@明日` `@金曜` `@来週月曜` `@月末` |
| `!` | 優先度 | `!高` `!中` `!低`（`!!` でも高） |
| `#` | タグ | `#案件A` `#経理` |
| `>` | 依頼者 | `>山田` |

記号を使わなくても、「来週水曜までに見積」のように書けば期限は自動で読み取ります。

## 電話依頼を記録する

**📞 電話メモ** を押し、相手・連絡先・用件を入力。

- 期限を空にすると、用件の文章（「明日までに」等）から自動判定
- 「折り返し電話が必要」にチェックすると、タイトルに（折返し要）、タグに `折返し` が付く
- 受付日時は自動で記録

## AI・メモから取り込む

### 方法1: 画面に貼り付ける（いちばん確実）

1. **📋 AI・メモ取込** →「AI に頼むときの定型文」を開いて **コピー**
2. Claude / ChatGPT の会話の最後にその定型文を送る
3. AI が出力した箇条書きを全部コピー → 取込画面に貼り付け → 出典を選んで **解析**
4. 候補を確認（チェックを外す・タイトルや期限を直す）→ **タスクに登録** または **未整理へ**

定型文（画面からコピーできるものと同じ）:

```
この会話（または以下の文章）から、私がやるべきタスクだけを抽出してください。
出力は次の形式で1行1件、説明文は不要です。
- タスク名（動詞で終わる具体的な行動） @期限(yyyy-mm-dd・不明なら省略) !優先度(高/中/低) #案件名
今日は 2026-10-13 です。相対的な日付は具体的な日付に直してください。
```

> Claude の「プロジェクト」や ChatGPT の「カスタム指示」にこの定型文を入れておくと、毎回貼る手間が省けます。

箇条書きでない普通の文章（会議メモ等）を貼った場合は、Gemini（有効時）が抽出します。Gemini が無効なら1件の候補になるので、手で分けてください。

### 方法2: メールで送る（スマホから便利）

`自分+task@gmail.com`（画面上部に表示）宛にメールすると、次回の取込で **未整理** に入ります。

- 件名の先頭に `[Claude]` `[ChatGPT]` `[メモ]` `[電話]` を付けると出典が分かれます
- 本文が箇条書きなら1行ずつ別のタスクになります
- スマホのメモアプリ・AI アプリの **共有 → メール** から送れます

## スプレッドシートを直接編集する

データは「TaskHub データ」スプレッドシートの **タスク** シートにあります。まとめて期限を変える、過去分を整理するなどは、シートで直接編集してOKです。

守ってほしいこと:
- **1行目の見出しは変えない**（列の並べ替え・列の追加はOK）
- **ID 列は変えない・消さない**
- 「状態」「優先度」はプルダウンから選ぶ
- 期限は `2026-10-20` の形で入力
- 行を消すより「状態 = 却下」にする（同じメールが再取込されるのを防ぐため）
- 新しい行を手で追加する場合、ID は空欄でOK（次に画面を開いたときに自動で付きます）。状態を空にすると「未着手」になります

## 複数アカウントの見分け方

タスクの編集画面に「作成日時 / アカウント」が表示されます。シートでは「アカウント」列で絞り込めます。
