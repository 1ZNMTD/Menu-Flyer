# セキュリティと注意点

TaskHub はメール本文など機密性のある情報を扱います。想定されるリスクと、その対策（実装済み / 利用者が行うこと）をまとめます。

## 1. 情報の置き場所と流れ

| データ | 置き場所 | 見られる人 |
|---|---|---|
| タスク・メールの抜粋 | メインアカウントの Google ドライブ（スプレッドシート） | 自分（＋共有した会社アカウント） |
| 設定・API キー | Apps Script のスクリプト プロパティ | スクリプトの編集者（自分のみ） |
| ソースコード | GitHub（非公開リポジトリ） | 自分。**秘密情報は含まない** |
| AI 抽出時のメール本文 | Gemini API（Google）へ送信 | Google（下記 2 を参照） |

## 2. 無料の Gemini API と学習利用 ⚠️

- 無料枠では、送信した内容が **Google のサービス改善（人によるレビューを含む）に利用される場合があります**。
- 対策:
  - 機密性の高いメールが多いアカウントは、そのスクリプトで `AI_MODE` = `rules` に設定（外部送信ゼロ）
  - 取込対象を Gmail フィルタで絞る（AI に送るのは `taskhub-in` 等に一致したメールだけ）
  - 送るのは件名・差出人・本文（引用部分を除き最大6,000字）のみ。添付ファイルは送らない
  - 将来、学習利用されない有料プランに切り替えることも可能（コード変更不要、キーを差し替えるだけ）
- **課金（お支払い情報）を登録しない** こと。登録しなければ上限超過時も請求されません。

## 3. 実装済みの対策

| リスク | 対策 |
|---|---|
| 画面に他人がアクセス | ウェブアプリのアクセスを「自分のみ」に固定（マニフェストで指定）。さらに全サーバー関数でログイン中のアカウントを確認 |
| メール本文に仕込まれたスクリプト（XSS） | 画面の表示はすべて文字列として描画（HTML として解釈しない）。まとめメールも HTML エスケープ |
| リンク偽装（`javascript:` 等） | リンクは `https://` のみ許可 |
| 数式インジェクション（件名 `=IMPORTXML(...)` 等でシートから情報を外部送信） | `= + - @` で始まる値は文字列として保存 |
| AI への指示の乗っ取り（メール本文に「以前の指示を無視して…」） | 本文はデータとして扱うよう指示。AI の出力は型・長さ・値を検証。**自動確定せず必ず「未整理」を通す** |
| 他サイトへの埋め込み（クリックジャッキング） | 埋め込みを禁止 |
| API キーの漏えい | キーはスクリプト プロパティのみに保存。URL に含めず HTTP ヘッダーで送信。エラーログにも残さない |
| 無料枠・実行時間の超過 | Gemini は1日80回・1回5件まで。超過時は自動でルール抽出。1回の取込は30通・4分まで、残りは次回 |
| 取込の二重実行・重複登録 | メール ID で重複チェック。同時実行を防止 |

## 4. 利用者にお願いしたいこと

1. **Google アカウント（個人・会社とも）で2段階認証を有効にする** — アカウントが乗っ取られると全データが見られます
2. スプレッドシート・スクリプトを **他人と共有しない**。共有設定が「リンクを知っている全員」になっていないか時々確認
3. ウェブアプリのデプロイ設定は **「アクセスできるユーザー: 自分のみ」** から変えない
4. API キーを GitHub・チャット・メールに貼らない。漏れたら AI Studio でキーを削除して作り直す
5. （推奨）Google Cloud コンソールで API キーの利用先を「Generative Language API」のみに制限する
6. 「至急振込」などの **詐欺メールもタスク候補になり得ます**。「元メール」で差出人を確認してから対応する
7. 月1回程度、スプレッドシートを「ファイル → ダウンロード → Excel」でバックアップ
8. 会社のアカウントを使わなくなる（退職・異動）ときは、会社側の collector で `uninstall` を実行し、スプレッドシートの共有を解除する

## 5. 権限（スコープ）について

Apps Script の `GmailApp` は仕組み上 Gmail 全体へのアクセス権を要求します。TaskHub のコードが行う Gmail 操作は次の3つだけです。

- 検索条件に一致するメールの **読み取り**
- ラベル `taskhub-in` / `taskhub-done` の **作成と付与**
- まとめメールの **送信**（自分宛）

メールの削除・転送・他人への送信は行いません。更新時は `src/` の差分を確認してから貼り付けてください。

## 6. 見落としのリスクと対策

| 見落としの原因 | 対策 |
|---|---|
| Gmail フィルタの条件漏れ | 週1回フィルタを見直す。迷ったら手動でラベル `taskhub-in` を付ける |
| 迷惑メールに振り分けられた | 転送用アドレスに「迷惑メールにしない」フィルタ |
| 取込エラー | Google から失敗通知メールが届く。まとめメールにも直近のエラー件数が出る。シート「ログ」で確認 |
| ルール抽出の期限ミス | 「未整理」で確認してから採用する運用で補う |
| 未整理の放置 | まとめメールに未整理件数を表示 |
