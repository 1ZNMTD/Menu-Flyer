# セットアップ手順

所要時間: 基本設定 約15分 ＋ 取込元ごとの設定 各5分程度。
すべてブラウザ（PC 推奨）で行います。プログラムの知識は不要で、**コピー＆貼り付け** だけです。

> 用意するもの
> - メインにする Google アカウント（個人の Gmail を推奨）
> - このリポジトリの `dist/` フォルダにある3つのファイル: `Code.gs` / `Index.html` / `appsscript.json`

---

## ステップ1：Apps Script のプロジェクトを作る

1. メインの Google アカウントでログインした状態で <https://script.google.com/> を開く
2. 左上の **「新しいプロジェクト」** をクリック
3. 左上の「無題のプロジェクト」をクリックして名前を **TaskHub** に変更
4. 左の歯車アイコン **「プロジェクトの設定」** を開き、
   **「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック** を入れる
5. 同じ画面の「タイムゾーン」が **(GMT+09:00) 日本標準時** であることを確認

## ステップ2：ファイルを貼り付ける

左の **「エディタ」**（`< >` アイコン）に戻ります。

| エディタ上のファイル | 操作 |
|---|---|
| `appsscript.json` | 中身を全部消して `dist/appsscript.json` の中身を貼り付け |
| `コード.gs` | 中身を全部消して `dist/Code.gs` の中身を貼り付け |
| （新規）`Index` | 「ファイル」の横の **＋ → HTML** を選び、名前を **`Index`**（拡張子なし、I は大文字）にして、`dist/Index.html` の中身を貼り付け |

最後に **保存（Ctrl+S / ⌘+S）**。

> GitHub でファイルを開き、右上の「Copy raw file」ボタンを使うと全文を正確にコピーできます。

## ステップ3：初期設定を実行する

1. エディタ上部の関数選択で **`setup`** を選び **「実行」**
2. 「承認が必要です」→ **権限を確認** → 自分のアカウントを選択
3. 「このアプリは Google で確認されていません」と出たら **詳細 → TaskHub（安全ではないページ）に移動**
   - 自分で作ったスクリプトなので Google の審査を受けていない、という意味です。他人が作ったスクリプトでこの画面が出たら進まないでください。
4. 許可する権限: Gmail（取込・ラベル付け）、スプレッドシート、外部サービスへの接続（Gemini）、メール送信（まとめメール）、トリガー
5. 実行ログに `完了` と表示されればOK。ログにある **スプレッドシートのURL** を開いて「タスク」シートがあることを確認

この時点で、Gmail にラベル `taskhub-in` と `taskhub-done` ができ、15分ごとの取込・毎朝7時のまとめメール・毎週の整理が自動で動き始めます。

## ステップ4：画面（Web アプリ）を公開する

1. 右上の **「デプロイ」→「新しいデプロイ」**
2. 歯車 →「種類の選択」で **ウェブアプリ**
3. 設定:
   - 説明: `v1.0`
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ** ← 必ずこれ（他人にメール内容が見えるのを防ぐ）
4. **デプロイ** → 表示された **ウェブアプリの URL** をコピー
5. PC: ブラウザでブックマーク
6. スマホ: その URL をスマホのブラウザで開き（同じ Google アカウントでログイン）、
   - iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
   - Android（Chrome）: メニュー →「ホーム画面に追加」

> URL は他人に教えないでください（「自分のみ」なので他人は開けませんが、念のため）。

## ステップ5：AI 抽出（Gemini）を有効にする（任意・無料）

使わない場合はスキップ可。ルール抽出だけでも動きます。

1. <https://aistudio.google.com/apikey> を開き **「API キーを作成」**
   - **お支払い（課金）情報は登録しないでください。** 登録しなければ無料枠を超えても請求は発生せず、エラーになるだけです（TaskHub は自動でルール抽出に切り替えます）
2. 作成されたキーをコピー
3. Apps Script の **プロジェクトの設定 → スクリプト プロパティ → 「スクリプト プロパティを追加」**
   - プロパティ: `GEMINI_API_KEY` / 値: コピーしたキー
4. エディタで関数 **`testGemini`** を実行 → ログに抽出結果（JSON）が出れば成功

> ⚠️ 無料枠では、送った内容が Google のサービス改善に利用される場合があります。詳しくは [SECURITY.md](SECURITY.md)。
> 特定のアカウント（例: 会社用）だけ AI を使わないようにするには、そのスクリプトのプロパティで `AI_MODE` = `rules` にします。

## ステップ6：取込元ごとの設定

### 6-1. Gmail（個人）— どのメールをタスク候補にするか

Gmail の **フィルタ** で、タスクになりそうなメールにラベル `taskhub-in` を付けます。

1. Gmail の検索窓右の「検索オプション」を開く
2. 条件を入力（例は下表）→ **フィルタを作成** → **「ラベルを付ける: taskhub-in」** にチェック → 作成

| 目的 | 条件の例 |
|---|---|
| 依頼っぽいメール | 含むキーワード: `(お願い OR 依頼 OR 至急 OR 期限 OR 締切 OR ご確認)` |
| 特定の取引先・上司 | From: `boss@example.com OR @client.co.jp` |
| 自分で手動で選ぶ | フィルタ不要。メールを開いてラベル `taskhub-in` を付けるだけ |

ポイント:
- 最初は条件を **狭め** に。多すぎると「未整理」が溢れます。慣れたら広げる
- 取り込まれたメールのスレッドには `taskhub-done` ラベルが付きます
- **`自分+task@gmail.com` 宛のメールは常に取り込まれます**（ラベル不要）

### 6-2. 会社の Google Workspace（Gmail）

**方法A（推奨）: 会社アカウントに「取込専用」を置く**

1. メインの「TaskHub データ」スプレッドシートを、会社アカウントに **編集者** として共有
   （会社のポリシーで外部共有が禁止されている場合は方法Bへ）
2. 会社アカウントで <https://script.google.com/> を開き、ステップ1〜2と同じように新規プロジェクトを作成してファイルを貼り付け
3. プロジェクトの設定 → スクリプト プロパティに追加:
   - `SPREADSHEET_ID` = メインのスプレッドシートの ID（URL の `/d/` と `/edit` の間の文字列）
   - `ACCOUNT_NAME` = `会社`（シートでどのアカウントから来たか分かるように）
   - （AI を使う場合）`GEMINI_API_KEY`。使わない場合は `AI_MODE` = `rules`
4. 関数 **`setupCollector`** を実行して承認
5. 会社の Gmail でも 6-1 と同じフィルタ（ラベル `taskhub-in`）を作成

画面の公開（ステップ4）は不要です。メインの画面に「アカウント: 会社」として表示されます。

**方法B: 会社 Gmail から個人 Gmail へ自動転送**

会社 Gmail の設定 → 転送 → 転送先に `自分+work@gmail.com` を追加（確認コードは個人 Gmail に届く）→ 会社 Gmail で「条件に合うメールを転送」のフィルタを作成。
個人 Gmail 側では `deliveredto:自分+work@gmail.com` のフィルタで（転送メールの宛先欄は元のままなので `to:` ではなく `deliveredto:` を使う） **ラベル taskhub-in** と **「迷惑メールにしない」** を設定。
※ 管理者が自動転送を禁止している場合は使えません。

### 6-3. その他のメール（エックスサーバー等の独自ドメインメール）

Gmail の「他のアカウントのメールを確認（POP）」は廃止されたため、**メールサーバー側で Gmail へ転送** します。

- エックスサーバー: サーバーパネル → メールアカウント設定 → 対象アカウントの「転送設定」→ 転送先 `自分+mail@gmail.com`（「メールボックスに残す」推奨）
- 個人 Gmail でフィルタを2つ作成
  1. `deliveredto:自分+mail@gmail.com` → **迷惑メールにしない**（転送メールは迷惑メール判定されやすく、迷惑メールは取り込まれないため）
  2. `deliveredto:自分+mail@gmail.com (お願い OR 依頼 OR 至急 OR 期限)` → **ラベル taskhub-in**
  - フィルタの条件は「検索オプション」ではなく、検索窓に直接入力して検索 → 検索オプションを開く → 「フィルタを作成」で作れます

### 6-4. NIコラボ

1. NIコラボの個人設定で、通知メール（新着メッセージ・ワークフロー・依頼など）を **ON**、宛先を Gmail（個人または会社）に
2. Gmail で NIコラボの通知メールの送信元を確認し、フィルタ `from:(その送信元)` → **ラベル taskhub-in**
3. 出典を「NIコラボ」と表示させるため、スクリプト プロパティ `NICOLLABO_FROM` に送信元アドレスを設定（カンマ区切りで複数可）
   - 本文に「NI Collabo」と書かれた通知は設定なしでも自動判定されます

### 6-5. Claude / ChatGPT / メモ

設定不要。使い方は [USAGE.md](USAGE.md) の「AI・メモから取り込む」を参照。

## 更新するとき（新しいバージョンが出たら）

1. `コード.gs` と `Index` の中身を新しい `dist/` の内容で置き換えて保存
2. 必要なら `setup` をもう一度実行（何度実行してもデータは消えません）
3. **デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン: 新バージョン → デプロイ**
   （「新しいデプロイ」にすると URL が変わってしまうので注意）

## 止めたいとき

関数 **`uninstall`** を実行すると自動処理が全て止まります（データは残ります）。再開は `setup`。

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| メールが取り込まれない | 関数 `checkStatus` を実行してログを確認。Gmail で検索条件（ログに表示）を貼り付けて検索し、メールがヒットするか |
| 迷惑メールに入ったメール | 取り込まれません。フィルタで「迷惑メールにしない」を設定 |
| 「アクセス権がありません」 | ウェブアプリを開いている Google アカウントが、デプロイしたアカウントと同じか（スマホで別アカウントになっていないか）。同じなのに出る場合は、デプロイの「アクセスできるユーザー」が **自分のみ** であることを確認したうえで、スクリプト プロパティ `SKIP_USER_CHECK` = `true` を追加 |
| AI が使われない | `testGemini` を実行。シート「ログ」に Gemini のエラーがないか。無料枠の上限に達すると1時間ルール抽出になります |
| エラーの通知メールが来た | シート「ログ」を確認。一時的なものは次回の実行で自動回復します |

## 設定項目一覧（スクリプト プロパティ）

| キー | 既定値 | 説明 |
|---|---|---|
| `GEMINI_API_KEY` | （なし） | Gemini の API キー |
| `AI_MODE` | `gemini` | `rules` にすると外部 AI へ一切送信しない |
| `GEMINI_MODEL` | `gemini-flash-latest` | 使うモデル名 |
| `GEMINI_DAILY_LIMIT` | `80` | 1日の Gemini 呼び出し上限 |
| `GEMINI_PER_RUN_LIMIT` | `5` | 1回の取込で Gemini を使う最大件数 |
| `GMAIL_QUERY` | `(label:taskhub-in OR to:{PLUS}) -in:spam -in:trash` | 取込対象の Gmail 検索条件。`{PLUS}` は `自分+task@…` に置換 |
| `INITIAL_LOOKBACK_DAYS` | `3` | 初回に何日前まで遡るか |
| `MAX_MESSAGES_PER_RUN` | `30` | 1回に処理する最大メール数（残りは次回） |
| `DIGEST_HOUR` | `7` | まとめメールの時刻（変更後は `setup` を再実行） |
| `DIGEST_TO` | 自分 | まとめメールの宛先 |
| `DIGEST_SKIP_EMPTY` | `true` | 何もない日は送らない |
| `ARCHIVE_AFTER_DAYS` | `30` | 完了・却下から何日でアーカイブするか |
| `ACCOUNT_NAME` | メールアドレス | シートに記録するアカウント名 |
| `NICOLLABO_FROM` | （なし） | NIコラボ通知の送信元アドレス |
| `ALLOWED_EMAILS` | 自分 | 画面を使えるアカウント（通常は変更不要） |
| `SPREADSHEET_ID` | 自動 | データのスプレッドシート ID |
